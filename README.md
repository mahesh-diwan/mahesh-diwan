<details>
<summary>🥚 <b>Easter Egg #2/3</b>: The icon journey</summary>
<br>
These icons use <strong>icoziv</strong> — a Workers.dev proxy that serves Simple Icons with gradient fills. Before this, the stack used <code>skillicons.dev</code> with the <code>theme=dark</code> param. The switch happened because icoziv offers per-icon customization with <code>radius</code> and <code>width</code> params, making every icon consistently 36px with 8px corner radius. One library, one shape, one size — the #1 rule from the README audit.
</details>

<details>
<summary><strong>🔧 Automation & Architecture</strong></summary>

This profile is **fully automated** via GitHub Actions running daily at ~06:00 UTC:

| Workflow                 | Schedule  | Purpose                                                    |
| ------------------------ | --------- | ---------------------------------------------------------- |
| `update-profile-art.yml` | 06:17 UTC | ASCII portrait, info card, contribution heatmap, data JSON |
| `metrics.yml`            | 06:22 UTC | Terminal-themed metrics SVG (lowlighter/metrics)           |
| `snake.yml`              | 06:30 UTC | Contribution snake animation (Platane/snk)                 |
| `update-readme.yml`      | 06:35 UTC | **New** — Recent releases, blog posts, dynamic sections    |

**Generated assets** (committed to `assets/` and `data/`):

- `mahesh-ascii.svg` — ASCII portrait from photo
- `info-card.svg` — Neofetch-style system info card
- `contrib-heatmap.svg` — Contribution calendar heatmap
- `github-snake*.svg` — Animated contribution snake
- `metrics.svg` — Comprehensive GitHub metrics
- `contributions.json` — Raw contribution data

**Stack:** Python 3.11 + GitHub Actions + lowlighter/metrics + Platane/snk + custom scripts

</details>
